# CommitLens

GitHub repository analytics dashboard for developers.

## Features

- Repository URL parser
- Development statistics dashboard
- Commit activity visualization
- Language breakdown
- Development timeline
- Repository signals
- Responsive dark interface

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
